De Mateo, Jocelyn O.

Project title: Pizza Ordering System

Description: The Forno Classico Pizza Ordering System is a user-friendly application that makes ordering pizza simple and convenient. Customer can choose from five artisan pizza flavors, select a crust size, add extra toppings, and enter a quantity between 1 and 50. The system validates the quantity, asks for confirmation before placing the order, and automatically calculates the total cost to display an itemized receipt. It also includes a reset button to clear all selections and start a new order.
